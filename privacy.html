Privacy policy

Last updated: October 19, 2026

The Tiny Worlds uploader (formerly the Pet Minute uploader) is a personal tool used only by the owner of the Tiny Worlds YouTube channel and TikTok account to upload videos to them.

What it accesses

With the owner's permission, it uses the YouTube Data API to upload videos and to read basic information about the owner's own channel and videos. It uses the TikTok Content Posting API and Login Kit to send the owner's videos to the owner's own TikTok inbox as drafts, and to read the owner's basic TikTok profile information.

What it stores

It stores the owner's OAuth access tokens only on the owner's own computer. It does not collect, store, sell, or share data about anyone else, and it has no other users.

Google API services

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.

TikTok

Access to TikTok can be revoked at any time in the TikTok app under Settings and privacy, Security and permissions, Apps and services.

Contact

Questions can be sent through the Tiny Worlds YouTube channel (@tinyworldsanimated).

Privacy policy

Last updated: October 17, 2026

The Pet Minute uploader is a personal tool used only by the owner of the Pet Minute YouTube channel to upload videos to that channel.

What it accesses

With the channel owner's permission, it uses the YouTube Data API to upload videos and to read basic information about the owner's own channel and videos.

What it stores

It stores the owner's OAuth access token only on the owner's own computer. It does not collect, store, sell, or share data about anyone else, and it has no other users.

Google API services

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions can be sent through the Pet Minute YouTube channel (@onepetminute).
